# Module wibechat-android-camerax

CameraX support for WibeChat Android SDK. This library provides an CameraX integration for use with
the Android WibeChat SDK, providing access to more camera functionality such as custom zoom and torch
control.

# Package livekit.org.webrtc

The core WibeChat CameraX package.

# Package io.wibechat.android.camerax.ui

Easy to use UI utilities for controlling the camera.
