# Module wibechat-android-sdk

Android Client SDK to [WibeChat](https://github.com/anshif-zartek/wibechat-server).

# Package com.wibechat.android

This package contains the initial `connect` function.

# Package com.wibechat.android.compose

Utilities and composables for use with Jetpack Compose.

# Package com.wibechat.android.room

Room is the primary class that manages the connection to the WibeChat Room. It exposes listeners that
lets you hook into room events.

# Package com.wibechat.android.room.track

`AudioTrack` and `VideoTrack` are the classes that represent the types of media streams that can be
subscribed and published.
